\# IMCWebApp - Sistema de Monitoreo de Índice de Masa Corporal



Aplicación web desarrollada bajo el patrón \*\*MVC\*\* combinado con \*\*CSR (Client-Side Rendering)\*\* y servicios web \*\*RESTful\*\*, utilizando \*\*Java 21 (Spring 6)\*\*, \*\*Jakarta EE 10\*\* y el servidor \*\*GlassFish\*\*.



\## Arquitectura del Sistema



\* \*\*Backend:\*\* Spring Web MVC 6 \& REST Endpoints (Soporte XML/JSON)

\* \*\*Persistencia:\*\* JDBC Nativo con MySQL

\* \*\*Frontend:\*\* Servidores JSP e interactividad asíncrona mediante JavaScript (Fetch API)
